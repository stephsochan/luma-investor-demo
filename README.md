# Luma Investor Demo — v190

Interactive investor build based on the actual Luma v190 web application.

## What investors can click through
- Frequency discovery and profiles
- Matches and seeded messaging
- Virtual Date 15/30/60 minute flow
- Safety Center, report/block concepts
- Wallet and monetization preview surfaces
- Investor tour and 7-minute demo runbook
- Release gates, proof map, FAQ and diligence views

The build opens in **PARTNER DEMO** automatically. Preview/gated functionality is labeled inside the product; no real payments, payouts, identity verification, live calls/video or production signing are claimed.

## GitHub Pages
Upload the **contents of this folder** to the repository root on the `main` branch. Then open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.

Expected URL after GitHub finishes deployment:
`https://stephsochan.github.io/luma-investor-demo/`

Do not present that URL as live until GitHub Pages shows a successful deployment.
